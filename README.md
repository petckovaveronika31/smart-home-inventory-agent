# Умный помощник по домашним запасам

## Описание проекта

**Умный помощник по домашним запасам** — это ИИ-агент для учёта продуктов, контроля сроков годности и рационального использования домашних запасов.

Цель проекта — помочь пользователю контролировать имеющиеся продукты, своевременно использовать продукты с приближающимся сроком годности и эффективнее планировать приготовление пищи.

## Язык программирования и хранение данных

- **Язык программирования:** `Python`.
- **Планируемая СУБД:** `PostgreSQL`.
- **Язык запросов к базе данных:** `SQL`.

В дальнейшем база данных будет использоваться для хранения информации о продуктах, их количестве, сроках годности и статусе использования. На текущем этапе база данных ещё не реализована.
