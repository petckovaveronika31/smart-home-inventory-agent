# Умный помощник по домашним запасам

## Описание проекта

**Умный помощник по домашним запасам** — это ИИ-агент для учёта продуктов, контроля сроков годности и рационального использования домашних запасов.

Цель проекта — помочь пользователю контролировать имеющиеся продукты, своевременно использовать продукты с приближающимся сроком годности и эффективнее планировать приготовление пищи.

## Язык программирования и хранение данных

- **Язык программирования:** `Python`.
- **Планируемая СУБД:** `PostgreSQL`.
- **Язык запросов к базе данных:** `SQL`.

В дальнейшем база данных будет использоваться для хранения информации о продуктах, их количестве, сроках годности и статусе использования. На текущем этапе база данных ещё не реализована.




## Планируемые возможности

1. Добавление продуктов с указанием названия, количества и срока годности.
2. Просмотр списка продуктов, находящихся в домашних запасах.
3. Поиск продуктов по названию.
4. Выявление продуктов с приближающимся сроком годности.
5. Отметка продуктов, которые уже использованы.
6. Предложение вариантов блюд на основе имеющихся продуктов.

## Примеры взаимодействия с агентом

**Запрос пользователя 1:**

`Какие продукты скоро испортятся?`

**Ожидаемый результат:** агент выводит список продуктов с приближающимся сроком годности и указывает, какие из них желательно использовать в первую очередь.

**Запрос пользователя 2:**

`Что можно приготовить из курицы, риса и моркови?`

**Ожидаемый результат:** агент предлагает несколько вариантов блюд, для приготовления которых можно использовать перечисленные продукты.

## Перспективы развития

В последующих лабораторных работах планируется расширить функциональность агента, реализовать хранение данных в `PostgreSQL` и добавить взаимодействие с пользователем.
