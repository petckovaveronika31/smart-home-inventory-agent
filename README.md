
# Умный помощник по домашним запасам

Консольный прототип ИИ-агента для учёта домашних запасов. Приложение позволяет добавлять продукты, просматривать запасы, учитывать сроки годности и списывать использованные продукты.

## Технологический стек

| Компонент | Значение |
|---|---|
| IDE / редактор | Visual Studio Code |
| Язык и версия | Python 3.12+ |
| Среда выполнения | Интерпретатор Python |
| Менеджер зависимостей | pip + `requirements.txt` |
| Хранение данных | JSON-файл |
| Автоматическое тестирование | pytest |
| Измерение покрытия | pytest-cov |
| Линтер | Ruff |
| Форматтер | Ruff |

## Подготовка окружения и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/petckovaveronika31/smart-home-inventory-agent.git
cd smart-home-inventory-agent
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите приложение:

```bash
python run.py
```

## Команды приложения

| Команда | Назначение |
|---|---|
| `add <название> <количество> <ГГГГ-ММ-ДД>` | Добавить партию продукта |
| `list` | Показать все запасы и их статусы |
| `consume <название> <количество>` | Списать продукт |
| `help` | Показать справку |
| `exit` | Завершить работу приложения |

Названия продуктов, состоящие из нескольких слов, необходимо заключать в кавычки.

## Хранение и восстановление состояния

Для хранения данных используется JSON-файл:

```text
data/inventory.json
```

Файл содержит сведения о продуктах и их партиях. Для каждого продукта сохраняется список партий с количеством и сроком годности.

При запуске приложения выполняется загрузка сохранённого состояния из JSON-файла.

Если файл ещё не существует, приложение начинает работу с пустым состоянием. Каталог и файл создаются при первой успешной операции добавления продукта.

Состояние автоматически сохраняется после успешного добавления продукта и после успешного списания.

Таким образом, изменения сохраняются без необходимости выполнять отдельную команду сохранения. После перезапуска приложения ранее добавленные продукты и результаты операций восстановления остаются доступными.

При ошибках чтения или записи хранилища приложение выводит сообщение об ошибке.

Локальные данные из каталога `data/` исключены из Git с помощью `.gitignore`.

## Автоматическое тестирование

Для автоматического тестирования используется библиотека `pytest`.

Запуск всех тестов:

```bash
python -m pytest -v
```

Тесты расположены в каталоге `tests/` и проверяют:

- первое создание пустого состояния;
- добавление и сохранение продуктов;
- восстановление состояния из JSON;
- сохранение результатов списания;
- обработку повреждённого JSON;
- проверку пользовательского ввода;
- обработку ошибок и основных операций приложения.

## Измерение покрытия кода

Для измерения покрытия строк используется `pytest-cov`.

Команда запуска тестов с отчётом о покрытии:

```bash
python -m pytest --cov=app --cov-report=term-missing
```

Для формирования HTML-отчёта:

```bash
python -m pytest --cov=app --cov-report=html
```

HTML-отчёт создаётся в каталоге `htmlcov/`.

Локальные отчёты о покрытии исключены из Git.

## Проверки качества кода

В проекте используется Ruff.

Проверка кода линтером:

```bash
python -m ruff check .
```

Проверка форматирования:

```bash
python -m ruff format --check .
```

Автоматическое форматирование файлов:

```bash
python -m ruff format .
```

## Штатное завершение

Для завершения работы приложения введите:

```text
exit
```

## Примеры диалога

### Пример 1. Добавление и просмотр продуктов

```text
> add молоко 2 2027-12-31
Добавлено: молоко, 2 шт., срок 2027-12-31.

> add молоко 1 2028-01-15
Добавлено: молоко, 1 шт., срок 2028-01-15.

> list
молоко: 2 шт., срок 2027-12-31, статус Свежий
молоко: 1 шт., срок 2028-01-15, статус Свежий
```

### Пример 2. Списание продукта

```text
> add "хлеб белый" 3 2027-12-25
Добавлено: хлеб белый, 3 шт., срок 2027-12-25.

> consume "хлеб белый" 1
Списано 1 шт. 'хлеб белый'.

> list
хлеб белый: 2 шт., срок 2027-12-25, статус Свежий
```

После повторного запуска приложения сохранённое состояние восстанавливается.
